# Amazon GIF vs Flipkart BBD: 2026 Festive E-Commerce Case Study

An interactive, high-performance case study web application analyzing the **₹1.5 Lakh Crore** Indian festive e-commerce showdown between **Amazon's Great Indian Festival (GIF)** and **Flipkart's Big Billion Days (BBD)**.

## 🚀 Key Features

- **3D Interactive Visuals**: Custom Three.js particle constellation and wireframe Torus geometry with dynamic mouse parallax.
- **Realistic 3D Tilt Cards**: Vanilla Tilt physics with glare effects on metrics and analysis cards.
- **Interactive Data Visualizations**:
  - **Chart 1**: Headline Growth Signals (Selective metrics comparisons).
  - **Chart 2**: Multiples of a Normal Day (Order surge 14x vs GMV 6x).
  - **Chart 3**: 8-Dimension Qualitative Radar Scorecard.
- **Filterable Head-to-Head Matrix**: Filter across Customer & Reach, Product & Commerce, and Governance & Transparency.
- **Quick-Commerce Speed Breakdown**: Sub-5 minute delivery metrics (Flipkart Minutes vs Amazon Now).

---

## 🛠️ Tech Stack

- **HTML5 & Modern CSS3**
- **Tailwind CSS** (via CDN)
- **Three.js** (WebGL 3D background effects)
- **Chart.js** (Dynamic charts and radar scorecards)
- **Vanilla Tilt.js** (3D physics card hover effects)
- **FontAwesome 6** (Vector icons)

## 💻 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   cd <repo-name>
   ```

2. Open `index.html` in any modern web browser:
   - On Windows: Double click `index.html` or run:
     ```powershell
     Start-Process index.html
     ```
   - Or use VS Code Live Server / any static file server:
     ```bash
     npx serve .
     ```

## 🌐 Deploy to GitHub Pages (Free)

1. Go to your repository on GitHub.
2. Navigate to **Settings** > **Pages** (under Code and automation).
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**.
5. Your website will be live at `https://<your-username>.github.io/<repo-name>/` in ~1-2 minutes!
